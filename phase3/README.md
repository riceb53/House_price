# County Housing Explorer (simple student project)

## What is real right now?

The `data/` folder includes actual Zillow annual home values and NOAA county weather.
Permits and unemployment are not included yet. Their columns in `merged.csv` are **blank**, not invented.
All 2026 source rows are partial-year measurements, so ETL uses complete-year records only.

## Run it on your Mac

Open this folder in VS Code, then in Terminal:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python etl.py
streamlit run streamlit_app.py
```

A browser window opens at http://localhost:8501.

## Run the API too

In a second Terminal in this folder:

```bash
source .venv/bin/activate
uvicorn api:app --reload --port 8000
```

API docs: http://localhost:8000/docs

To make Streamlit call this API, stop Streamlit in the first terminal with Control+C, then:

```bash
export API_URL=http://localhost:8000
streamlit run streamlit_app.py
```

## Files

- `etl.py`: joins Zillow and NOAA by 5-digit county FIPS + year
- `data/merged.csv`: combined annual data generated by `etl.py`
- `data_utils.py`: calculates year-over-year home value changes and permit lags
- `api.py`: FastAPI endpoints (`/counties`, `/prices`, `/weather`, `/merged`, `/permits`)
- `streamlit_app.py`: three-tab dashboard with sidebar filters
- `Dockerfile.api` and `Dockerfile.streamlit`: the two future Cloud Run services
